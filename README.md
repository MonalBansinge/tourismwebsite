# Tourism Website 🌍

A simple and responsive tourism website built using HTML and CSS. This project showcases tourist destinations through an attractive and user-friendly webpage design.

## ✨ Features

- Clean and simple user interface
- Tourist destination presentation
- Styled layouts using CSS
- Responsive design basics
- Easy-to-navigate webpage

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```text
tourismwebsite/
├── index.html
├── style.css
└── README.md
```

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/MonalBansinge/tourismwebsite.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
